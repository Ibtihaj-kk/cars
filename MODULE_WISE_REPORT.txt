2) High-Level Request Flow

2.1 Request lifecycle (common)
1. Request comes in → routed by yallamotor_project/urls.py
2. Middleware runs (notably):
   - Currency selection: core.middleware.CurrencyMiddleware
   - Vendor gating: business_partners.middleware.VendorAccessMiddleware
   - User restriction: users.middleware.UserRestrictionMiddleware
3. View executes (template or API)
4. Templates have shared context processors (cart count, vendor flags, currency)

No separate React/Vue frontend (no package.json found). The “frontend” is:
- Django templates under /templates (public pages, user pages, vendor pages, admin panel pages)
- HTMX endpoints for partial updates

Step 0 — Add items to cart
- Auth: DB cart
- Guest: session cart
- Stock checks enforced before increasing quantities

Step 1 — Order Summary
URL: GET/POST /parts/checkout/step1/ → checkout_step1_order_summary()
- Resolves cart items (DB vs session)
- Computes tax per item based on part.tax_classification_material (default 15%)
- Applies discount code from session applied_discount_code
- On proceed_to_shipping persists request.session['checkout_data'] with items_total + discount info
Code:
- parts/views.py: file:///c:/Users/Ibtihaj/.gemini/antigravity/scratch/yallamotor-analysis/parts/views.py#L3203-L3404

Step 2 — Shipping Info
URL: GET/POST /parts/checkout/step2/ → checkout_step2_shipping_info()
- Requires checkout_data from step1
- Accepts contact + address + city + area fields
- Computes shipping via ShippingRate(city), fallback default 25.00
- Computes tax again and sets grand_total
- Saves updated checkout_data back to session and redirects to step3
Code:
- parts/views.py: file:///c:/Users/Ibtihaj/.gemini/antigravity/scratch/yallamotor-analysis/parts/views.py#L3406-L3626

10) Key Takeaways / “How it really works”

- The “frontend” user shopping experience is primarily Django templates:
  browse parts → add to cart → checkout → place order → confirmation.
- Checkout supports:
  authenticated users (DB-backed cart) and guests (session cart),
  discount codes + shipping rates by city,
  inventory deduction with InventoryTransaction logging.
- Parallel auth infrastructure exists:
  session-based web login, JWT auth endpoints, vendor-specific login + optional 2FA.
  Some HTMX auth code conflicts with the custom AUTH_USER_MODEL and should be treated cautiously.
